How to import event data

  1. Download example CSV · Download example XLSX and open it in your spreadsheet editor.
  2. Keep the column headers and replace the example rows with your attendees. Save as CSV UTF-8 (comma-delimited) or Excel (.xlsx).
  3. Ensure each tier matches a Tier in Tier Backgrounds. Add any new Tiers there before importing.
  4. Select your file under Attendee CSV / XLSX. Optionally select an Avatar folder, then click Import event.
  5. Use View a badge to check the result. Export directly in RGB, or select CMYK and a printer ICC / ICM profile under Export for print.

For XLSX, put the headers in the first row of the first worksheet. Only that worksheet is imported. Use plain values rather than formulas, and format ticket IDs and barcode content as Text before entering them to preserve leading zeros and long numbers.

For Google Sheets, choose File → Download → Microsoft Excel (.xlsx), then upload the downloaded file here.

CSV / XLSX columns

number — optional
Row number. If omitted or empty, it is filled automatically.
ticket_id — required
A unique ticket ID for each attendee, such as S-002. Keep IDs as text to preserve leading zeros.
display_name — required
The name printed on the badge.
tier — required
The matching Tier name, such as Attendees, Sponsors, or Super Sponsors.
qr_token — required
The content encoded in QR Code, Data Matrix, or Aztec. Keep this column name for every barcode type. Example tokens are placeholders; replace them with your own values.

Optional avatars

Name each image after its ticket ID: S-002.png, S-002.jpg, or S-002.jpeg. Keep only one matching image per ticket ID. Do not add image paths to the spreadsheet.

Missing avatars leave the avatar area transparent. Images only appear on Tiers with avatars enabled.

How to use an avatar mask

A mask controls which parts of the avatar are visible. Use it to crop an avatar into a circle, a rounded shape, or a custom outline.

Prepare your PNG

  • PNG with transparency: opaque areas show the avatar; transparent areas hide it. Partly transparent areas create soft edges. The mask's color does not matter.
  • PNG without transparency: white shows the avatar, black hides it, and gray makes it partly visible.

If your PNG has an alpha (transparency) channel, the app uses that channel. An opaque black area will still show the avatar. For a black-and-white mask, export a grayscale PNG without an alpha channel.

Example: a circular avatar

Create a square PNG with a solid circle in the middle and a transparent background. Keep the avatar frame square so the circle stays round.

Apply the mask

  1. Select the Avatar layer in Layers.
  2. Choose your PNG under Mask PNG, then click Upload mask.
  3. Adjust Fit, Image scale, and Image X / Y % to position the avatar.
  4. Click Save layout, then check the result in View a badge.

The mask is stretched to the avatar frame, so use a matching aspect ratio. It applies to avatars in this Tier and does not change the original image files. Upload another mask to replace it, or click Remove mask to restore the unmasked avatar. You can Undo the change; click Save layout to keep it.

Permanently delete all saved data?

All your saved layouts will be deleted. This also deletes:

  • Custom Tiers, backgrounds, artwork, and avatar masks
  • Imported attendee lists and avatars
  • Generated badges, export files, uploaded fonts, and font caches

This cannot be undone in the app. The built-in starter Tiers will be available after reset.
